# Four Directions

Football story-game prototype: choices, training, relationships, four schools and simplified 11v11 matches.

## Play the new walkable pixel game

Open `pixel_game/index.html` in your browser (or VS Code Live Server). Explore 13 connected maps from home to city, school interiors and the football ground. Episode 1 includes dialogue choices, trial club membership, passing training and browser save/load. No install required.

## Play the original prototype on Windows

Install Python 3 with tkinter. Download this repository as a ZIP and extract it. Open `football_story` and double-click `Start_Windows.bat`. The launcher installs Pillow.

Or run from `football_story`:

```sh
python -m pip install -r requirements.txt
python game.py
```

## Read Episode 1

Open `story/Episode_1.html` in your browser after downloading the repository. Keep the `art` directory beside `story`. The plain script is `story/Episode_1.txt`.

## Contents

- `football_story/`: existing playable Python/Tkinter prototype and original school/kit galleries.
- `story/`: new illustrated Episode 1 and dialogue/choice script.
- `art/`: four campus backgrounds, five southern-school locations and five character expression sheets.

The new chapter and artwork are supplied separately; the existing prototype has not yet been updated to play this longer script. Its match engine is a simplified seeded event simulation, not full football physics. Full romance routes and later chapters remain unfinished. Original generated PNG artwork is provided here as compressed JPEG copies.

Story premise: Gun captained six equally skilled teammates to a national title in their first middle-school year. They then stopped playing. Hachiman and Kaito attend Minami Seiryu; their return begins with trial club membership.

This is a crossover fan project using existing fictional characters. No ownership of the original characters or commercial licence is claimed.
